System Architecture

The platform has two clear tiers. The browser owns keys, plaintext, and analytics. The API handles authentication and encrypted storage without receiving readable training history.

  • Client: buildless HTML, CSS, and JavaScript app with Web Crypto, IndexedDB, PWA caching, and local analytics.
  • Server: Node.js and Express API backed by PostgreSQL, with HTTP-only sessions, rate limits, structured logs, and health checks.

Data Flow

  1. You enter a password on the client.
  2. Argon2id and HKDF derive deterministic client-side key material.
  3. ML-DSA-65 signs a server-issued login nonce.
  4. The client encrypts workout data with AES-256-GCM and uses ML-KEM-768 to encapsulate a fresh sync key.
  5. The server stores public keys, the encrypted blob, and the KEM ciphertext in PostgreSQL.
  6. On retrieval, the client decapsulates and decrypts the blob locally, then calculates analytics in the browser.
