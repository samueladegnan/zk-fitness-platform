ZK Fitness

Privacy-first fitness tracking with zero-knowledge encryption.

Launch Live Demo

System Architecture

The system is split into two primary tiers:

  • Client (Frontend): HTML5/Vanilla JS app that handles cryptographic operations, UI/UX, and local state management.
  • Server (Backend): Node.js/Express API backed by PostgreSQL, containerized with Docker for easy deployment.

Zero-Knowledge Flow

  1. The user enters a password in the browser.
  2. Argon2id derives both an authentication key and an encryption key from the password.
  3. The client encrypts workout data with AES-256-GCM before sending it to the server.
  4. The server stores the encrypted blob in PostgreSQL.
  5. On retrieval, the client decrypts the blob locally with the user’s key.

Technology Stack

Component Technology Purpose
