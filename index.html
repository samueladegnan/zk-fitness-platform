ZK Fitness

A workout tracker designed so your training history stays yours.

Launch Live Demo

A privacy-first workout tracker

ZK Fitness is a full-stack strength and cardio tracker built around a simple constraint: the service should not be able to read a user's training history. Local mode works without an account; cloud sync stores only encrypted payloads.

What happens to the data

The browser derives keys locally with Argon2id and encrypts workout state with AES-256-GCM before sync. The API persists opaque blobs and public key material, while workout analytics stay on the client.

Authentication uses ML-DSA-65 signatures. ML-KEM-768 wraps a fresh data key for each sync, giving the project a practical post-quantum cryptography path without moving private keys off the device.

What you can explore

  • Log strength and cardio sessions, create reusable plans, and inspect progress over time.
  • Run the complete demo locally with IndexedDB persistence and offline app-shell caching.
  • Review the client/server boundary in the architecture notes and inspect the automated security report.
  • Deploy the API with PostgreSQL and Docker, or use local mode without a backend.
