Zero-Knowledge Gamified Fitness Platform

A privacy-first, full-stack strength training platform where your workout data is encrypted in the browser before it ever reaches the cloud.

Full-Stack Zero-Knowledge Web Crypto API Production-Ready

What It Is

The Zero-Knowledge Gamified Fitness Platform is a strength-training application that proves you can build modern cloud features without sacrificing user privacy. The server stores only encrypted blobs and cannot read any workout, body-weight, or progress metric.

The Problem

Traditional workout apps collect sensitive personal health metrics on centralized servers, creating privacy risks and trapping user data in proprietary ecosystems without robust user-controlled security.

The Solution

  • Client-side encryption with the Web Crypto API (AES-256-GCM).
  • Keys derived from user credentials via Argon2id and never transmitted.
  • A zero-trust Node.js API and PostgreSQL backend that only stores opaque payloads.
  • A browser-based gamification engine for XP, tonnage, and progressive-overload analytics.

Architecture

The platform separates trust domains: all plaintext data lives in the browser, and the cloud only ever sees ciphertext.

Security Model

  1. The server never receives the user's password.
  2. The client derives an authentication key and an separate encryption key from the password using Argon2id + HKDF.
  3. The authentication key is hashed and verified server-side; the encryption key is never transmitted.
  4. The server stores only the authentication hash and the encrypted blob.
  5. All transport is encrypted with TLS 1.3.
