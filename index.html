What it does

ZK Fitness is a full-stack strength and cardio tracker built around a clear privacy boundary. The browser owns keys, readable workout data, and analytics. The API stores public key material and opaque encrypted payloads.

  • Log strength, cardio, and time-based sessions with reusable plans.
  • Track records, charts, badges, XP, and personal progress locally.
  • Try the full product without an account using encrypted local persistence.
  • Run the API with PostgreSQL and Docker when cross-device sync is needed.

How it works

Argon2id and HKDF derive client-side key material. AES-256-GCM encrypts workout state before sync. ML-DSA-65 authenticates login requests, while ML-KEM-768 encapsulates a fresh sync data key. Private keys and plaintext workouts stay on the device.

Engineering focus

  • Offline-first product behavior: local mode is fully usable without an account, with IndexedDB persistence and browser-side analytics.
  • Small, explicit trust boundary: the API manages sessions and encrypted storage, while the client owns readable workout state and cryptographic keys.
  • Production discipline: the repository includes migrations, health checks, structured logs, Docker support, end-to-end coverage, and automated security review.
