Install ZK Fitness

On iPhone or iPad, open this site in Safari, tap Share, choose Add to Home Screen, then tap Add.

iOS does not expose a native web install prompt. Once added, ZK Fitness opens in its own app-style window and keeps its local data available offline.

Your data stays yours

Workouts are encrypted in the browser before they are stored. The server cannot read cloud-synced workouts.

  • In account mode, your password derives the client keys. Your password and private keys do not leave this device.
  • Cloud sync sends public key material and encrypted payloads, not readable workouts.
  • Local trial mode encrypts its IndexedDB record to demonstrate the storage boundary. It is not a replacement for device security because the demo key is available to the app.
  • The browser, device, password, dependencies, and deployment configuration remain part of the trust model.

Warming up...

The first post-quantum key generation can take a few seconds. If the server has been idle, waking it up can take up to a minute. Please wait.
