Install ZK Fitness

On iPhone or iPad, open this site in Safari, tap Share, choose Add to Home Screen, then tap Add.

iOS does not expose a native web install prompt. Once added, ZK Fitness opens in its own app-style window and keeps its static shell available offline. Account sync still needs the API connection.

Understand local mode

Local mode encrypts the IndexedDB record before storage so the storage shape matches the account path.

  • Account mode derives client key material from your password. The password and private keys are not sent to the API.
  • Cloud sync sends public key material and encrypted payloads, not readable workouts.
  • Local trial mode uses a fixed demonstration key. It protects against casual storage inspection, but code running in this same origin can access the key.
  • The browser, device, password, dependencies, and deployment configuration remain part of the trust model.

Warming up...

The first post-quantum key generation can take a few seconds. If the server has been idle, waking it up can take up to a minute. Please wait.
