Your data stays yours

Workouts are encrypted on this device before they go anywhere. Even the server cannot read them.

  • End-to-end on-device encryption: your password and private keys never leave this device.
  • AES-256-GCM protects your local data; the symmetric key is derived from your password with Argon2id.
  • If you later enable cloud sync, only post-quantum public key material (ML-DSA-65 + ML-KEM-768) is sent to the server for authentication and key encapsulation.
  • Argon2id key derivation runs locally, hardening your password against brute-force attacks.

Warming up…

The first post-quantum key generation can take a few seconds. If the server has been idle, waking it up can take up to a minute. Please hang tight.
