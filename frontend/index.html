Zero-Knowledge Security Demo

Before you begin, here is how this app protects your data:

  • Zero-Knowledge Architecture: We never know your password. Keys are derived client-side using Argon2id.
  • Post-Quantum Authentication: Login uses an ML-DSA-65 signature. The server stores only your public key.
  • Post-Quantum Key Encapsulation: Every sync uses ML-KEM-768 to wrap a fresh AES-256-GCM data key. The server stores only the ciphertext.
  • End-to-End Encryption: Every workout is encrypted in your browser with AES-256-GCM.
  • Server Cannot Read Data: The backend only stores public keys and random-looking ciphertext. It has no access to plaintext.
  • Demo Mode is Local: No server is used. Your data is encrypted and stored only in your browser's local storage.

Warming up…

The first post-quantum key generation can take a few seconds. Please hang tight.
