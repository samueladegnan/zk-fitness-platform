Live Demo

Launch the live demo above to explore the app in your browser with no account required. Data is stored locally in your browser and never reaches a server in demo mode.

Run It Locally

To run the project manually on your own machine, use the following commands:

# 1. Clone the repository
git clone https://github.com/samueladegnan/zk-gamified-fitness-platform.git
cd zk-gamified-fitness-platform

# 2. Start the backend services (Node.js & PostgreSQL)
docker-compose up -d

# 3. Serve the frontend
cd frontend
npx serve .

What to Try

  • Click Try Demo Mode on the login screen to skip registration.
  • Start an empty workout, add strength and cardio exercises, and log a few sets.
  • Finish the workout and watch the XP, level, and badge updates.
  • Browse the Plans tab to create or edit a workout template.
  • Open the History tab to view and edit past workouts.
