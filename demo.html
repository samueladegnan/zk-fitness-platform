ZK Fitness

Keep your workout history private. Encrypted on your device, readable only by you.

Launch Live Demo

Live Demo

Launch the live demo above to explore the app without an account. Local mode stores data on your device and never touches a server. Cloud sync uses ML-DSA-65 and ML-KEM-768 for post-quantum authentication and key encapsulation.

Run It Locally

To run the project on your own machine:

# 1. Clone the repository
git clone https://github.com/samueladegnan/zk-fitness-platform.git
cd zk-fitness-platform

# 2. Install backend dependencies and start the database
npm run install:backend
npm run dev:infra

# 3. Run migrations and start the API
npm run migrate
npm start

# 4. Serve the frontend (in a new terminal)
npx serve frontend -l 3001
