ZK Fitness

Privacy-first fitness tracking with zero-knowledge encryption.

Launch Live Demo

Live Demo

Launch the live demo above to explore the app in your browser with no account required. Data is stored locally in your browser and never reaches a server in demo mode. The live (non-demo) app uses ML-DSA-65 and ML-KEM-768 for post-quantum authentication and key encapsulation.

Run It Locally

To run the project manually on your own machine, use the following commands:

# 1. Clone the repository
git clone https://github.com/samueladegnan/zk-fitness-platform.git
cd zk-fitness-platform

# 2. Start the backend services (Node.js & PostgreSQL)
docker-compose up -d

# 3. Serve the frontend
cd frontend
npx serve .

What to Try

  • Click Try Demo Mode on the login screen to skip registration.

  • Finish the workout and watch the XP, level, and badge updates.
  • Browse the Plans tab to create or edit a workout template.
  • Open the History tab to view and edit past workouts.
