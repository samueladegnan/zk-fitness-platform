Run It Locally

To run the project on your own machine:

# 1. Clone the repository
git clone https://github.com/samueladegnan/zk-fitness-platform.git
cd zk-fitness-platform

# 2. Install backend dependencies and start the database
npm run install:backend
npm run dev:infra

# 3. Run migrations and start the API
npm run migrate
npm start

# 4. Serve the frontend (in a new terminal)
npx serve frontend -l 3001

Suggested walkthrough

  1. Choose Try without an account to open local mode.
  2. Start an empty workout and add a strength or cardio exercise.
  3. Open an exercise card to inspect records, charts, and the one-rep-max estimate, then add it to the current workout.
  4. Create a plan, add exercises from search, and check that the editor resumes where you left it.
