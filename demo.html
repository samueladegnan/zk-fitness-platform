Try the working app

Hosted on GitHub Pages

Open the app and choose Try without an account. Local mode gives you the product flow without a signup step. Your sensitive fitness record stays in this browser.

Open the app

What to look for

  1. Choose Try without an account to open local mode.
  2. Start an empty workout and add a strength or cardio exercise.
  3. Open an exercise card to inspect records, charts, and the one-rep-max estimate.
  4. Create a plan, add an exercise from search, and confirm that the editor returns to the plan.
  5. Open the local mode explanation to see what the demonstration key does and does not protect.

Run the full stack locally

Local mode does not need the backend. Account mode and cloud sync do. Use Docker for PostgreSQL, then run the API and frontend in separate terminals.

git clone https://github.com/samueladegnan/zk-fitness-platform.git
cd zk-fitness-platform
npm ci
npm run install:frontend
npm run install:backend
cp backend/.env.example backend/.env
npm run dev:infra
npm run migrate
npm run dev:api

In a second terminal:

npm run dev:client

Open http://localhost:3001. The API listens on http://localhost:3000/api/health.
